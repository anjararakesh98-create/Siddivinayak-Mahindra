Update Stock from Excel

Upload the latest STOCK.xlsx each time. Changes are saved to the shared cloud database after secure setup. Sheet2 is used when it contains Chassis Number, Engine Number, SC Name and Customer Name.

Upload Excel / CSV

Rules: chassis number and engine number must be present and unique. Existing chassis records are updated; if engine number conflicts with another chassis, that row is rejected. Duplicate chassis/engine rows in the same upload are skipped. The summary reports accepted, updated, duplicate and rejected counts.
